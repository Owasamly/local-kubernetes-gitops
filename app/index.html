Healthy and synchronized

Local Kubernetes GitOps

This application is running inside Kubernetes and is continuously reconciled from Git by Argo CD.

1. Git Desired state is committed to the repository.
2. CI validation Helm, schemas and security controls verify each change.
3. Argo CD Drift is detected and the approved revision is synchronized.
4. Kubernetes k3d runs the declared workload across local agent nodes.
Deployment method: Helm + Argo CD Environment: k3d / k3s
